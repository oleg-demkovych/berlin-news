# Берлін сьогодні

Новини Берліна з кількох видань в одному місці, з перекладом українською та щогодинним оновленням.

**Сайт:** https://oleg-demkovych.github.io/berlin-news/

## Можливості
- Пошук, фільтри за категорією, періодом і джерелом
- Переклад заголовків та описів українською (кнопка «Перекласти українською»)
- Посилання «Стаття українською» відкриває статтю через Google Translate
- Збережені та прочитані матеріали (у браузері вашого пристрою)
- Світла й темна теми
- PWA: встановлення на телефон і перегляд останніх завантажених новин без інтернету

## Встановлення на телефон
- **Android (Chrome):** відкрийте сайт → «Встановити», або меню ⋮ → «Додати на головний екран».
- **iPhone (Safari):** відкрийте сайт → «Поділитися» → «На початковий екран».

## Джерела

| Категорія | Видання |
|---|---|
| Новини | rbb24, Tagesspiegel, Berliner Morgenpost, Berliner Zeitung, taz Berlin |
| Поліція | Поліція Берліна |
| Місто | Entwicklungsstadt |
| Культура і дозвілля | Mit Vergnügen, iHeartBerlin |
| English | The Local Berlin, The Berlin Spectator |
| Українською | DW (лише матеріали зі згадкою «Берлін») |

Щоб додати джерело, допишіть його в `scripts/sources.json`:

```json
{"name": "Назва", "cat": "Новини", "url": "https://example.com/feed.xml"}
```

Необов'язкові поля: `filter` (регулярний вираз для відбору) і `max` (ліміт матеріалів).
Для нового англомовного джерела додайте його назву також у `ENGLISH` у `scripts/translate.py`, інакше текст перекладатиметься як німецький.

## Як це працює
Workflow `.github/workflows/update.yml` запускається за розкладом (щогодини, на 7-й хвилині), після пушу в `main` або вручну:

1. `scripts/fetch.mjs` читає RSS/Atom-стрічки та зберігає матеріали за останні 30 днів (до 3000).
2. `scripts/translate.py` перекладає ще не перекладені матеріали, спершу найновіші. На переклад відведено близько 20 хвилин за запуск, решта переходить на наступний. Якщо крок не вдасться, сайт опублікується без нових перекладів.
3. Папка `public` публікується на GitHub Pages.

Через переклад збірка може тривати понад 20 хвилин. GitHub може затримувати запуски за розкладом і вимикає розклад у публічних репозиторіях після 60 днів без активності.

## Налаштування з нуля
Settings → Pages → Source: **GitHub Actions**, потім Actions → «Оновлення новин» → Run workflow.

## Локальний запуск
Потрібен Node.js 20+:

```bash
node server.mjs
```

Відкрийте http://localhost:3000. Переклад необов'язковий і потребує Python:

```bash
pip install torch transformers==4.48.3 sentencepiece==0.2.0 sacremoses==0.1.1
python scripts/translate.py   # після того, як створено public/data/news.json
```

Локальний сервер щогодини перезаписує новини; переклади незмінених матеріалів зберігаються.

## Структура
```
public/            сайт, маніфест, service worker, іконки
scripts/           збір новин, переклад, список джерел
server.mjs         локальний сервер
.github/workflows/ щогодинна збірка
```

## Якість перекладу та ліцензії
- Переклад автоматичний і може містити помилки. Перевіряйте важливу інформацію за оригіналом.
- Модель [NLLB-200](https://huggingface.co/facebook/nllb-200-distilled-600M) поширюється за ліцензією CC-BY-NC 4.0: лише некомерційне використання.
- Права на матеріали належать виданням. Застосунок показує заголовки, короткі описи та посилання на оригінали.
